## Dispositions

- **TT-1 [MEDIUM], fixed — controller resize disk accounting.** A stopped
  16 MiB VM on a 32 MiB host could forward a 64 MiB resize because the target was
  attached before computing growth. Allowed growth also left host disk counters
  unchanged until refresh. The agent's independent capacity guard limited the
  consequence; the controller still violated its admission/reservation contract.
  `a8a5ab8` calculates growth from the previous reservation and commits VM intent
  and host counters together. Fresh definitive rejections return the charge;
  exact retries reuse it. Regressions failed before the fix and now cover
  over-budget rejection before forwarding, durable charging, retry and rollback
  on a host-write failure. Existing lost-response and backup tests pass.
- **TT-2 [LOW], fixed — local deployment build guidance.** Missing local agent
  binaries recommended Cargo; missing controller/CLI binaries omitted the
  documented Go hint. `b97de42` consistently recommends `make release` and records
  that existing deliberate diagnostic deviation in compatibility section 7.
  All three missing-binary regressions failed before the fix and now pass using
  fake commands and private temporary directories.
- Custom controller data-directory setup was not recorded as a defect:
  `tools/deploy.toml.example` explicitly requires operator-prepared write access.
  Conservative retention and documented FreeBSD/OpenRC limitations were not
  treated as new parity defects.
