TTstack CLI — manage your private cloud from the command line.

Usage: tt [OPTIONS] <COMMAND>

Commands:
  config        Configure the controller address and optional API key
  capabilities  Show technical engine/storage support, including FreeBSD 15.x platforms
  status        Show fleet-wide status
  host          Manage physical hosts
  env           Manage environments
  image         Manage images
  deploy        Deploy TTstack to local or remote hosts
  help          Print this message or the help of the given subcommand(s)

Options:
  -s, --server <SERVER>    Controller address; saved credentials are reused only for the same address
  -k, --api-key <API_KEY>  API key for controller authentication [env: TT_API_KEY=]
  -h, --help               Print help
  -V, --version            Print version
