Manage physical hosts

Usage: tt host [OPTIONS] <COMMAND>

Commands:
  add     Register a new host by its agent address
  list    List all hosts
  show    Show host details
  remove  Remove a host from the fleet
  detach  Forget an offline host and print orphaned VMs; does not stop or delete them
  help    Print this message or the help of the given subcommand(s)

Options:
  -s, --server <SERVER>    Controller address; saved credentials are reused only for the same address
  -k, --api-key <API_KEY>  API key for controller authentication [env: TT_API_KEY=]
  -h, --help               Print help
