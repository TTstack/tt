Deploy agent and controller on this Linux/systemd host (requires root)

Usage: tt deploy all [OPTIONS]

Options:
      --release-dir <RELEASE_DIR>  Path to release binaries directory [default: ./target/release]
  -s, --server <SERVER>            Controller address; saved credentials are reused only for the same address
  -k, --api-key <API_KEY>          API key for controller authentication [env: TT_API_KEY=]
  -h, --help                       Print help
