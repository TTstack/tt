Manage environments

Usage: tt env [OPTIONS] <COMMAND>

Commands:
  backup  Inspect or explicitly manage one lightweight disk recovery point
  create  Create a new environment with VMs
  list    List all environments
  show    Show environment details
  delete  Delete an environment
  stop    Stop all VMs in an environment
  start   Start all VMs in an environment
  resize  Change one stopped QEMU/Firecracker VM; disk can only grow. Inspect env show for VM IDs
  help    Print this message or the help of the given subcommand(s)

Options:
  -s, --server <SERVER>    Controller address; saved credentials are reused only for the same address
  -k, --api-key <API_KEY>  API key for controller authentication [env: TT_API_KEY=]
  -h, --help               Print help
