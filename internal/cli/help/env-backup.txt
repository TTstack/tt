Inspect or explicitly manage one lightweight disk recovery point

Usage: tt env backup [OPTIONS] <COMMAND>

Commands:
  show     Show support, revision, recovery point, pending work and retirement status
  create   Create/refresh a stopped VM's backup; the agent must explicitly enable admission
  restore  Overwrite the stopped VM's disk with this recovery point; retains the backup
  delete   Remove the recovery point and its retired generations from a stopped VM
  help     Print this message or the help of the given subcommand(s)

Options:
  -s, --server <SERVER>    Controller address; saved credentials are reused only for the same address
  -k, --api-key <API_KEY>  API key for controller authentication [env: TT_API_KEY=]
  -h, --help               Print help
