Deploy TTstack to local or remote hosts

Usage: tt deploy [OPTIONS] <COMMAND>

Commands:
  agent  Deploy agent on this Linux/systemd host (requires root)
  ctl    Deploy controller on this Linux/systemd host (requires root)
  all    Deploy agent and controller on this Linux/systemd host (requires root)
  dist   Distributed deploy to all hosts defined in a config file
  help   Print this message or the help of the given subcommand(s)

Options:
  -s, --server <SERVER>    Controller address; saved credentials are reused only for the same address
  -k, --api-key <API_KEY>  API key for controller authentication [env: TT_API_KEY=]
  -h, --help               Print help
