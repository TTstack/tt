Manage images

Usage: tt image [OPTIONS] <COMMAND>

Commands:
  list     List file/zvol images reported by online hosts (excludes Docker images)
  recipes  List built-in image recipes that can be auto-created
  create   Create an image locally from a built-in recipe; run on the intended agent host
  help     Print this message or the help of the given subcommand(s)

Options:
  -s, --server <SERVER>    Controller address; saved credentials are reused only for the same address
  -k, --api-key <API_KEY>  API key for controller authentication [env: TT_API_KEY=]
  -h, --help               Print help
